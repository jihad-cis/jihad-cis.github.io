# Jihad Al-Wasabi — حزمة النشر المجانية

هذه الحزمة جاهزة لرفعها إلى مستودع GitHub Pages باسم `jihad-worlds`.

## الملفات
- `index.html` — الصفحة الرئيسية المستقلة.
- `404.html` — صفحة الخطأ.
- `icon.svg` — أيقونة الموقع.
- `manifest.webmanifest` — إعدادات التطبيق.

## طريقة الرفع
1. فك ضغط الحزمة على جهازك.
2. ارفع **الملفات الموجودة داخل المجلد** إلى جذر مستودع `jihad-worlds` (لا ترفع ملف ZIP نفسه).
3. تأكد أن `index.html` ظاهر في الجذر.
4. اضغط `Commit changes`.
5. في المستودع: `Settings` → `Pages` → `Deploy from a branch` → اختر `main` و`/(root)` ثم `Save`.

## تنبيه
هذه نسخة موقع ثابتة، لا تتطلب إعدادًا أو مفاتيح سرية. بعض المزايا المتصلة مثل إرسال رسائل فعليًا، المواعيد، المساعد المتصل بالخادم ولوحة الإدارة تحتاج خدمات خلفية منفصلة ولم يتم تفعيلها في هذه الحزمة. تمت مراجعة صياغة JavaScript آليًا، لكن الاختبار البصري النهائي يكون بعد النشر في المتصفح.
