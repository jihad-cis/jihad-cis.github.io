# Jihad — Architectural Digital Worlds | GitHub Pages Deployment

## رفع الموقع
1. افتح المستودع `jihad-worlds` في GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (وليس ملف ZIP نفسه).
3. تأكد أن `index.html` موجود مباشرة في جذر المستودع.
4. اضغط Commit changes.
5. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
6. انتظر حتى يظهر رابط الموقع.

## ملاحظات صادقة
- هذه نسخة نشر ثابتة تعتمد على `index.html` المستقل، ولا تحتاج إلى `config.js` أو خادم أثناء العرض.
- المساعد يعمل في الحدود المحلية الموجودة في الملف؛ المساعد الذكي المتصل بالخادم، إرسال الرسائل، المواعيد، لوحة الإدارة وقاعدة البيانات تحتاج إعداد Supabase منفصلًا، ولم يتم تفعيلها في هذه الحزمة.
- بعض الصور/الخطوط/الخريطة قد تعتمد على الإنترنت ومصادر خارجية.
- تمت فحوصات آلية للصياغة البرمجية والمراجع المحلية، لكنها ليست بديلًا عن تجربة المتصفح الفعلية بعد النشر.


## ملاحظات قبل النشر
- الملف الرئيسي هو `index.html`، ويجب أن يبقى في جذر المستودع.
- هذه نسخة واجهة ثابتة مناسبة لـ GitHub Pages؛ لا تتطلب تثبيت Node.js أو تشغيل خادم.
- المساعد يعمل بالوضع المحلي. الاتصال بنموذج ذكاء اصطناعي خارجي واستقبال الرسائل وحفظ المواعيد يحتاج إعداد خدمة خلفية منفصلًا، ولا تعتبر هذه الوظائف متصلة تلقائيًا بمجرد رفع الملفات.
- رمز QR يُحدّث عنوانه تلقائيًا عند فتح الموقع على عنوانه المنشور.
